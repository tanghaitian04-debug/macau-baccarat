# 澳门百家乐 V3 · 翡翠厅

可运行的 React / TypeScript 网页游戏，虚拟筹码娱乐与规则模拟。初始余额为100,000虚拟筹码，没有充值、支付、提现、兑换或其他真钱功能。

## V3 当前状态

详见 [V3升级交付与验收](V3_UPGRADE.md)。V3新增七种幸运边注、语音队列、逐张翻牌、原场景镜头咪牌与v2存档迁移。281项单元测试通过。下方原阶段表保留为初版基线，最新功能与缺口以V3文档为准。

## 本地运行

需要 Node.js 22 或更高版本：

```sh
npm ci
npm run dev
```

生产构建与自动化测试：

```sh
npm run test:report
npm run build
```

`dist/` 为可静态托管的产物；使用相对资源路径，可放在 GitHub Pages 子目录。直接双击 HTML 文件不等于启动应用，需要 HTTP/HTTPS 服务。

## 如何游玩

1. 点击“入座”，解锁浏览器音频。手机建议横屏。
2. 选择筹码面额，再点击投注区；桌面可拖动筹码到投注区。支持多项目、撤销、清除、重复上一局。
3. 点击“停止下注 · 发牌”。下注从此锁定，不能重复触发发牌。
4. 在3D牌桌上按住牌边慢拖，或点击“指尖咪牌”打开大画面。起点决定从左右或上下方向弯牌。拖动距离控制弯曲程度；未揭完松手则回弹。点击“直接开牌”打开当前批次的牌。
5. 双方初始牌完成开牌后，引擎严格按补牌表发第三张，玩家不能自行选择补或停。补发的牌也要开完，才进入结算。
6. 点击“下一局”。设置中可以切换自动开牌、结算模式、音量和渲染质量。
7. 点击左上路单查看珠盘路、大路、下三路及统计。重新开靴保留历史记录，清空当前靴路单并退回尚未开局的下注。

若浏览器无法创建WebGL上下文，程序会显示明确提示并使用可继续真实规则牌局的二维降级界面；这不是3D咪牌效果。降级界面可以逐张点击开牌或自动开牌。不能根据降级界面宣称3D表现已验证。

## 规则与金额

规则来源已于2026-11-11核对：

- [澳门博彩监察协调局规则索引](https://www.dicj.gov.mo/web/cn/rules/index.html)
- [第55/2004号：基础规则、发牌与补牌](https://www.dicj.gov.mo/web/cn/rules/Bacara.html)
- [第73/2005号：免佣庄六半赔](https://www.dicj.gov.mo/web/cn/rules/BacaraAlt01.html)
- [第2/2009号：七龙边注与免佣七龙退本](https://www.dicj.gov.mo/web/cn/rules/BacaraAlt04.html)
- [第56/2018号：烧牌选项等修订](https://www.dicj.gov.mo/web/cn/rules/BacaraAlt07.html)

本实现采用8副牌，烧8张（与牌副数相同的官方允许选项），切牌卡位于尾部14张之前。切牌卡到达时完成当前局，下局换靴。使用 `crypto.getRandomValues` 的拒绝采样Fisher–Yates洗牌，避免模偏差。实体牌ID由副数、花色、牌面组成，在单靴中不会重复发出。

金额单位为百分之一虚拟筹码的整数。筹码与下注始终是10虚拟筹码的整数倍，因此佣金与半赔都可精确表示，不需浮点金额舍入。赔率为净盈利，结算函数的 `paid` 包含退回的本金。

| 项目 | 净盈利 |
| --- | --- |
| 闲 | 1:1 |
| 庄（标准） | 0.95:1 |
| 和 | 8:1 |
| 庄对 / 闲对 | 11:1 |
| 七龙边注 | 40:1 |

免佣庄六模式：庄6点赢净赔0.5:1，其余庄赢1:1。七龙免佣模式：庄第三张补成7点且获胜，庄主注只退本，闲、和注输；七龙边注独立赔付。两张牌的7点不算七龙。和局退还庄闲主注本金；对子只看首两张同牌面，J与Q不算对子。

## 工程结构

```text
src/rules       纯规则与牌靴，不依赖React或Three.js
src/game        纯状态转换、Zustand状态、基于阶段的计时控制
src/roads       大路与派生路算法
src/cards       牌面纹理、网格弯曲、咪牌事件状态
src/dealer      程序化关节人物、GLB替换适配器
src/scene       牌桌、筹码、3D交互与无WebGL降级
src/audio       Web Audio合成音效、SpeechSynthesis、录音接口
src/ui          SVG路单面板
src/storage     IndexedDB事务保存
public/assets   正式美术与音频素材的预留目录
```

状态机：等待下注 → 停止下注 → 发牌 → 咪牌 → 按表补牌/咪牌 → 展示结果 → 结算 → 完成 → 下一局。每次状态转换保存完整快照。中途刷新恢复相同牌靴、实体牌与已开牌状态；结算记录使用唯一局ID防重复。IndexedDB失败会展示提示，隐私模式或清除站点数据可能删除浏览器记录；不提供跨设备同步。

路单：珠盘路逐局记录；大路六行、和局叠加、长龙碰撞转弯；下三路根据逻辑列高与缺口独立推导，红蓝表示整齐/不齐。算法不使用随机数，也不把派生路当作预测。

## 替换正式荷官与声音

`src/dealer/DealerModel.tsx` 的 `dealerAsset` 可指定经授权的GLB地址、尺寸、各阶段动画名称和嘴部Morph名称。默认 `null` 使用程序化人物。GLB应包含Idle、Deal、Collect等动画以及可选 `mouthOpen` Morph；模型的实际坐标、光照与动画片段需要对照素材调试。

`src/audio/audio.ts` 支持：

```ts
speak({
  text: '各位请下注。',
  url: '/assets/audio/bet.mp3',
  mouth: [
    {time: 0, open: 0},
    {time: 0.12, open: 0.7},
    {time: 0.3, open: 0.2},
    {time: 1.1, open: 0},
  ],
});
```

当前默认使用设备中文语音，不保证所有设备都有普通话女声。浏览器语音用语音播放期间的近似口型，录音模式可用时间轴线性插值。合成环境底噪不是实际赌场录音。
